01 — CONCEPT

What is Pairs Trading?

Imagine two siblings who always walk to school together. Sometimes one runs ahead, sometimes the other — but they always end up at school together. Pairs trading bets that if one sibling runs too far ahead, they'll slow down and wait for the other.

In financial terms: find two stocks that historically move together. When they diverge abnormally, short the overperformer and long the underperformer, expecting mean reversion.

📐

Market-Neutral

You're long one stock and short another — so broad market moves cancel out. You profit from relative performance, not market direction.

🔁

Mean-Reversion

The core bet: divergences between cointegrated stocks are temporary. The "spread" between them reverts to its long-run average.

🏦

Why HDFC + ICICI?

Both are large-cap Indian private banks, exposed to the same macro factors (RBI rates, credit cycle, NPA cycle) — strong candidates for cointegration.

📊

When Does It Work?

Best in range-bound, sideways markets. Struggles when one stock permanently re-rates (e.g., a merger or fraud scandal breaks the relationship).

Key Insight

Pairs trading is NOT about predicting which direction prices go. It's about predicting that the distance between two prices will return to normal. This makes it fundamentally different from directional trading.

02 — COINTEGRATION

Correlation vs Cointegration

This is where most beginners go wrong. Correlation ≠ Cointegration, and using the wrong one will blow up your strategy.

📈

Correlation

Measures if two stocks move in the same direction over a period. But two random walk stocks can appear correlated by chance (spurious correlation). It's unstable over time.

🔗

Cointegration

Measures if a linear combination of two non-stationary series is stationary (mean-reverting). This is the real test. Even if they drift, their spread stays bounded.

The Engle-Granger Test

We test: is the spread S_t = P_HDFC - β × P_ICICI stationary? If yes → cointegrated → pairs trade is valid.

H₀: No cointegration (spread has a unit root) H₁: Cointegration exists (spread is stationary) p-value < 0.05 → Reject H₀ → ✅ Proceed with strategy p-value ≥ 0.05 → Fail to reject H₀ → ❌ Don't trade this pair
Intuition

Think of two drunks walking home. If they're just correlated, they both stumble randomly. If they're cointegrated, they're tied together with a rubber band — they can wander, but they always snap back together.

cointegration_test.py
from statsmodels.tsa.stattools import coint
import numpy as np

# Test cointegration between HDFC and ICICI

print(f"Cointegration p-value: {pvalue:.4f}")
print(f"Critical values (1%, 5%, 10%): {critical_values}")

else:
    print("❌ Not cointegrated — avoid this pair")
03 — DATA + SPREAD

Downloading Data & Building the Spread

Step 1 — Download Stock Data

data_download.py
import yfinance as yf
import pandas as pd
import numpy as np

# Download 5 years of daily closing prices
tickers = ['HDFCBANK.NS', 'ICICIBANK.NS', '^NSEI']
raw = yf.download(tickers, start='2019-01-01', end='2024-01-01')

# Extract adjusted closing prices
prices = raw['Close'].dropna()
prices.columns = ['HDFCBANK', 'ICICIBANK', 'NIFTY']

print(prices.head())
print(f"Shape: {prices.shape}")   # ~1250 trading days

Step 2 — Calculate Hedge Ratio (Beta) via OLS Regression

We use Ordinary Least Squares to find how many shares of ICICI we need to short for every share of HDFC we buy. This is the hedge ratio β.

HDFCBANK = α + β × ICICIBANK + ε β (hedge ratio) tells us: "1 unit of HDFC ≈ β units of ICICI" Spread = HDFCBANK − β × ICICIBANK
hedge_ratio.py
from sklearn.linear_model import LinearRegression

# Fit OLS: HDFC = alpha + beta * ICICI
X = prices[['ICICIBANK']].values
y = prices['HDFCBANK'].values

model = LinearRegression().fit(X, y)
beta  = model.coef_[0]
alpha = model.intercept_

print(f"Hedge Ratio (β): {beta:.4f}")
print(f"Intercept (α):   {alpha:.4f}")

# Build the spread
prices['SPREAD'] = prices['HDFCBANK'] - beta * prices['ICICIBANK']

Step 3 — Compute Z-Score

The Z-score tells us how many standard deviations the spread is from its rolling mean. This is our signal.

Z-score = (Spread − Rolling_Mean) / Rolling_Std Rolling window = 60 trading days (≈ 3 months) Z > +2 → Spread is unusually HIGH → Short HDFC, Long ICICI Z < −2 → Spread is unusually LOW → Long HDFC, Short ICICI |Z| < 0.5 → Back to normal → Exit position
zscore.py
# Rolling Z-score with 60-day lookback window
window = 60

prices['SPREAD_MEAN'] = prices['SPREAD'].rolling(window).mean()
prices['SPREAD_STD']  = prices['SPREAD'].rolling(window).std()

prices['ZSCORE'] = (
    (prices['SPREAD'] - prices['SPREAD_MEAN'])
    / prices['SPREAD_STD']
)

# Drop NaN rows from rolling window warmup period
prices = prices.dropna()
Z-Score — Conceptual View
● Z > +2 → Entry (Short Spread) ● Z < -2 → Entry (Long Spread) — Z-Score path
04 — STRATEGY

Building the Trading Strategy

Now we convert Z-score signals into actual trade positions. The logic is simple but the implementation details matter enormously.

Trade Logic

Long Spread (Z < -2): Buy HDFC, Sell ICICI — betting spread rises back
Short Spread (Z > +2): Sell HDFC, Buy ICICI — betting spread falls back
Exit (|Z| < 0.5): Close both legs — profit captured

strategy_signals.py
# ── Signal thresholds ──────────────────────────────────────────
ENTRY_THRESHOLD = 2.0    # Enter when |Z| > 2
EXIT_THRESHOLD  = 0.5    # Exit when |Z| < 0.5

# ── Generate raw signals ───────────────────────────────────────
# +1 = Long spread, -1 = Short spread, 0 = Flat
prices['SIGNAL'] = 0
prices.loc[prices['ZSCORE'] < -ENTRY_THRESHOLD, 'SIGNAL'] = 1   # Long
prices.loc[prices['ZSCORE'] > ENTRY_THRESHOLD,  'SIGNAL'] = -1  # Short

# ── Convert signals to positions (hold until exit) ────────────
# This is the KEY step — we hold through intermediate days
position = 0
positions = []

for idx, row in prices.iterrows():
    z = row['ZSCORE']
    sig = row['SIGNAL']

    if position == 0:
        if   sig == 1:  position =  1  # New long entry
        elif sig == -1: position = -1  # New short entry
    elif position ==  1 and abs(z) < EXIT_THRESHOLD:
        position = 0   # Exit long position
    elif position == -1 and abs(z) < EXIT_THRESHOLD:
        position = 0   # Exit short position

    positions.append(position)

prices['POSITION'] = positions

# ── IMPORTANT: Shift position by 1 to avoid look-ahead bias ───
# We trade on NEXT day's open, not today's close!
prices['POSITION'] = prices['POSITION'].shift(1).fillna(0)
⚠ Look-Ahead Bias Warning

The .shift(1) is critical. Without it, you're pretending you traded at today's close using today's closing price signal — which is physically impossible. Always shift positions by 1 day.

05 — REGIME DETECTION

Market Regime Detection with Nifty 50

Pairs trading works differently in bull vs bear markets. We use the 200-day moving average of Nifty 50 to classify market regime.

Bull Regime: NIFTY_Close > NIFTY_200DMA (market trending up) Bear Regime: NIFTY_Close < NIFTY_200DMA (market trending down) Logic: When Nifty is ABOVE its 200DMA, we're in a structural uptrend. Mean reversion strategies tend to work better in range-bound markets.

🐂 Bull Regime

NIFTY > 200-day MA. Stocks trend strongly — correlations break, fundamentals re-rate, spread diverges more than expected. Strategy still works but with more noise.

🐻 Bear Regime

NIFTY < 200-day MA. Panic selling correlates all stocks. Spreads can blow out before reverting. Higher drawdowns, but mean-reversion signals are often sharp.

regime_detection.py
# ── 200-day moving average of Nifty 50 ────────────────────────
prices['NIFTY_MA200'] = prices['NIFTY'].rolling(200).mean()

# ── Classify regime ────────────────────────────────────────────
# 1 = Bull (above 200 DMA), 0 = Bear (below 200 DMA)
prices['REGIME'] = (prices['NIFTY'] > prices['NIFTY_MA200']).astype(int)

# ── Optional: Filter strategy to trade only in specific regimes
# Trade only in Bull market (empirically better for this strategy)
prices['POSITION_FILTERED'] = (
    prices['POSITION'] * prices['REGIME']
)

# Count regime days
bull_days = (prices['REGIME'] == 1).sum()
bear_days = (prices['REGIME'] == 0).sum()
print(f"Bull days: {bull_days} | Bear days: {bear_days}")
06 — BACKTEST

Backtesting with Transaction Costs

backtest.py
# ── Daily returns for each stock ──────────────────────────────
prices['RET_HDFC']  = prices['HDFCBANK'].pct_change()
prices['RET_ICICI'] = prices['ICICIBANK'].pct_change()

# ── Strategy daily return ─────────────────────────────────────
# Long spread  (+1): Long HDFC, Short ICICI
# Short spread (-1): Short HDFC, Long ICICI
prices['STRAT_RET'] = (
    prices['POSITION'] * (prices['RET_HDFC'] - beta * prices['RET_ICICI'])
)

# ── Transaction cost (realistic for Indian equities) ──────────
TRANSACTION_COST = 0.0005  # 5 bps per side (incl. STT, brokerage, impact)

# Detect trade days (when position changes)
trade_days = (prices['POSITION'].diff() != 0) & (prices['POSITION'] != 0)
prices['TC'] = 0.0
prices.loc[trade_days, 'TC'] = TRANSACTION_COST * 2  # Both legs

prices['STRAT_RET_NET'] = prices['STRAT_RET'] - prices['TC']

# ── Cumulative returns ─────────────────────────────────────────
prices['CUMRET']     = (1 + prices['STRAT_RET_NET']).cumprod() - 1

# ── Regime-split performance ───────────────────────────────────
for regime, label in [(1, 'Bull'), (0, 'Bear')]:
    subset = prices[prices['REGIME'] == regime]['STRAT_RET_NET']
    ann_ret  = subset.mean() * 252
    ann_vol  = subset.std()  * np.sqrt(252)
    sharpe   = ann_ret / ann_vol if ann_vol > 0 else 0
    print(f"{label} | Ann.Return={ann_ret:.2%} | Sharpe={sharpe:.2f}")

08 — RESULTS INTERPRETATION

When Does It Work? When Does It Fail?

✅

Works Best When…

Market is range-bound (Nifty sideways). The two banks are in similar credit cycles. No stock-specific news (earnings surprise, management change). Spread reverts within 10–20 days.

❌

Fails When…

One bank has a fraud/NPA scandal. RBI treats banks differently (e.g., differential rate signals). Strong trending market — spread keeps diverging. The 5-year cointegration window breaks.

Why Trending Markets Hurt

In a strong bull market, stocks re-rate based on earnings growth, not just relative value. HDFC might sustainably outperform ICICI for 12 months if it captures more market share. The Z-score hits +2 → you short HDFC → but HDFC keeps going up → you keep losing. The "spread" has structurally shifted, not temporarily diverged.

The Key Risk

Mean reversion is not guaranteed. The spread can widen to +3, +4, +5 standard deviations before reverting — or it might never revert. Always use stop-losses (e.g., exit if Z > 3.5, taking a loss rather than hoping for reversion).

09 — IMPROVEMENTS

Making the Strategy More Robust

  • Fix
    Rolling OLS hedge ratio — recalculate β every 60 days using a rolling regression instead of a fixed one. The relationship between HDFC and ICICI evolves over time.
  • Fix
    Kalman Filter for dynamic β — use a Kalman filter to track a time-varying hedge ratio in real-time. More responsive than rolling OLS, fewer lag artifacts.
  • Risk
    Stop-loss at Z = 3.5 — if Z exceeds 3.5, exit the trade at a loss rather than waiting for reversion. Prevents catastrophic blowup when cointegration breaks.
  • Risk
    Maximum holding period — if a trade hasn't resolved in 30 days, close it regardless of Z-score. Time-decay of the statistical relationship is real.
  • Idea
    Multiple pairs portfolio — run 5–10 cointegrated bank pairs simultaneously (AXISBANK, KOTAK, INDUSINDBK). Diversification smooths the equity curve dramatically.
  • Idea
    Volatility-scaled position sizing — reduce position size when spread volatility is high. Use Kelly criterion or 1/σ scaling to dynamically size each trade.
  • Idea
    Regime-conditional trading — only enter new positions when Nifty is in Bull regime. Still hold existing Bear regime positions to completion, but don't open new ones.
  • Fix
    Walk-forward validation — test your cointegration on Period A, trade on Period B, repeat. Avoids overfitting to a single historical window (in-sample vs out-of-sample split).

# ══════════════════════════════════════════════════════════════════
# PAIRS TRADING WITH MARKET REGIME DETECTION
# Stocks: HDFCBANK.NS + ICICIBANK.NS | Regime: ^NSEI (Nifty 50)
# ══════════════════════════════════════════════════════════════════

import warnings; warnings.filterwarnings('ignore')
import yfinance as yf
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
from sklearn.linear_model import LinearRegression
from statsmodels.tsa.stattools import coint, adfuller

# ─────────────────────────────────────────────────────────────────
# 1. DOWNLOAD DATA
# ─────────────────────────────────────────────────────────────────
tickers = ['HDFCBANK.NS', 'ICICIBANK.NS', '^NSEI']
raw = yf.download(tickers, start='2019-01-01', end='2024-01-01', auto_adjust=True)
prices = raw['Close'].dropna()
prices.columns = ['HDFCBANK', 'ICICIBANK', 'NIFTY']
print(f"✅ Downloaded {len(prices)} rows")

# ─────────────────────────────────────────────────────────────────
# 2. COINTEGRATION TEST (Engle-Granger)
# ─────────────────────────────────────────────────────────────────
score, pval, crits = coint(prices['HDFCBANK'], prices['ICICIBANK'])
print(f"\n📊 Cointegration p-value: {pval:.4f}")
print("✅ Cointegrated" if pval < 0.05 else "❌ Not cointegrated")

# ─────────────────────────────────────────────────────────────────
# 3. HEDGE RATIO VIA OLS
# ─────────────────────────────────────────────────────────────────
X = prices[['ICICIBANK']].values
y = prices['HDFCBANK'].values
model = LinearRegression().fit(X, y)
beta  = model.coef_[0]
print(f"\n📐 Hedge Ratio (β): {beta:.4f}")

# ─────────────────────────────────────────────────────────────────
# 4. SPREAD + Z-SCORE
# ─────────────────────────────────────────────────────────────────
WINDOW = 60
prices['SPREAD']      = prices['HDFCBANK'] - beta * prices['ICICIBANK']
prices['SPREAD_MEAN'] = prices['SPREAD'].rolling(WINDOW).mean()
prices['SPREAD_STD']  = prices['SPREAD'].rolling(WINDOW).std()
prices['ZSCORE']      = (prices['SPREAD'] - prices['SPREAD_MEAN']) / prices['SPREAD_STD']
prices = prices.dropna()

# ─────────────────────────────────────────────────────────────────
# 5. GENERATE POSITIONS (no look-ahead bias)
# ─────────────────────────────────────────────────────────────────
ENTRY = 2.0
EXIT  = 0.5
STOP  = 3.5   # Stop-loss Z level

position, positions = 0, []
for _, row in prices.iterrows():
    z = row['ZSCORE']
    if position == 0:
        if   z < -ENTRY: position =  1
        elif z >  ENTRY: position = -1
    elif position ==  1:
        if abs(z) < EXIT or z < -STOP: position = 0
    elif position == -1:
        if abs(z) < EXIT or z >  STOP: position = 0
    positions.append(position)

prices['POSITION'] = pd.Series(positions, index=prices.index).shift(1).fillna(0)

# ─────────────────────────────────────────────────────────────────
# 6. MARKET REGIME (Nifty 200 DMA)
# ─────────────────────────────────────────────────────────────────
prices['NIFTY_MA200'] = prices['NIFTY'].rolling(200).mean()
prices['REGIME']     = (prices['NIFTY'] > prices['NIFTY_MA200']).astype(int)

# ─────────────────────────────────────────────────────────────────
# 7. BACKTEST WITH TRANSACTION COSTS
# ─────────────────────────────────────────────────────────────────
TC_RATE = 0.0005   # 5 bps per trade side

prices['RET_HDFC']  = prices['HDFCBANK'].pct_change()
prices['RET_ICICI'] = prices['ICICIBANK'].pct_change()
prices['STRAT_RET'] = prices['POSITION'] * (prices['RET_HDFC'] - beta * prices['RET_ICICI'])

trade_days = prices['POSITION'].diff().abs() > 0
prices['STRAT_RET'] -= trade_days * TC_RATE * 2
prices['CUMRET']     = (1 + prices['STRAT_RET']).cumprod() - 1

# ─────────────────────────────────────────────────────────────────
# 8. PERFORMANCE SUMMARY
# ─────────────────────────────────────────────────────────────────
print("\n📈 PERFORMANCE SUMMARY")
print("-" * 45)
for regime, label in [(1, 'Bull'), (0, 'Bear'), (None, 'All ')]:
    subset = prices['STRAT_RET'] if regime is None else \
             prices[prices['REGIME'] == regime]['STRAT_RET']
    ann_r = subset.mean() * 252
    ann_v = subset.std()  * np.sqrt(252)
    sharpe = ann_r / ann_v if ann_v > 0 else 0
    maxdd  = ((1 + subset).cumprod() / (1 + subset).cumprod().cummax() - 1).min()
    print(f"{label} | Ret={ann_r:+.1%} | Vol={ann_v:.1%} | Sharpe={sharpe:.2f} | MaxDD={maxdd:.1%}")

# ─────────────────────────────────────────────────────────────────
# 9. VISUALISE
# ─────────────────────────────────────────────────────────────────

fig.patch.set_facecolor('#09090f')
for ax in [ax1, ax2, ax3]:
    ax.set_facecolor('#111118')
    ax.tick_params(colors='#7a7a96')
    for spine in ax.spines.values(): spine.set_edgecolor('#222230')
    ax.grid(True, alpha=0.1, color='#444')

ax1.plot(prices.index, prices['SPREAD'], color='#7c6af7', lw=1)
ax1.set_title('Spread (HDFCBANK − β·ICICIBANK)', color='#e8e8f0')
ax1.set_ylabel('₹', color='#7a7a96')

ax2.plot(prices.index, prices['ZSCORE'], color='#f7a04a', lw=1)
ax2.axhline( 2,  color='#f25c5c', ls='--', lw=1)
ax2.axhline(-2,  color='#3ecfb2', ls='--', lw=1)
ax2.axhline( 0,  color='#ffffff', ls='-',  lw=0.5, alpha=0.2)
ax2.fill_between(prices.index, prices['ZSCORE'], 0,
    where=prices['ZSCORE']>2,  alpha=0.2, color='#f25c5c')
ax2.fill_between(prices.index, prices['ZSCORE'], 0,
    where=prices['ZSCORE']<-2, alpha=0.2, color='#3ecfb2')
ax2.set_title('Z-Score | Red=Short Spread | Green=Long Spread', color='#e8e8f0')
ax2.set_ylabel('Z-Score', color='#7a7a96')

ax3.fill_between(prices.index, 0, 1,
    where=prices['REGIME']==1, alpha=0.07, color='#3ecfb2',
    transform=ax3.get_xaxis_transform(), label='Bull')
ax3.fill_between(prices.index, 0, 1,
    where=prices['REGIME']==0, alpha=0.07, color='#f25c5c',
    transform=ax3.get_xaxis_transform(), label='Bear')
ax3.plot(prices.index, prices['CUMRET'] * 100, color='#7c6af7', lw=1.5)
ax3.axhline(0, color='white', lw=0.5, alpha=0.2)
